# 用户指南

1. 启动“CAE 结果分析与报告工作台”。桌面端会自动启动本地 Server 和 Worker。
2. 点击“新建项目”，填写项目名称与项目根目录。
3. 选择外部 FEM 和 H3D。工作台只引用文件，不会复制或修改原文件。
4. 多选任务；选择热点或报告时，所需依赖会自动加入。
5. 创建后选择 Draft Run，点击“启动”。桌面端显示总体、阶段和当前任务进度。
6. 完成后点击“打开 Web 结果”，审查模型、网格、材料、边界条件、子工况和热点。
7. 在热点详情中批准、否决、申请重拍或恢复 HyperView 视图。

FEM 模型由多个文件组成时，在新建项目中只选择包含 `INCLUDE` 语句的头文件。
工作台会递归解析相对路径引用，并将头文件和所有 include 文件作为一个整体校验；任一
子文件缺失或发生变化时，会阻止使用旧指纹启动新的 Run。

HyperView 的 `hw.exe` 可在 Desktop 工具栏的“设置”中配置。保存后重启应用生效。
8. 在“报告”页调整幻灯片顺序、文本和素材，保存后导出 PPTX。

删除项目只会删除工作台生成的项目目录。确认框会明确提示，外部 FEM/H3D 永远不在删除范围内。

当 H3D 丢失或指纹变化时，历史结果仍可浏览；需要 H3D 的新任务会被禁止，重新定位并验证源文件后应创建新 Run。
